# Security policy

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub's security advisories](https://github.com/getsoundfolk/soundfolk/security/advisories/new): only the
maintainers see it. Say what an attacker could do, and how to reproduce it.

You will get an answer within a week. Once a fix is released, the advisory is published, with credit to you if you
wish.

## Supported versions

Only the latest release gets security fixes. Soundfolk updates itself (or through APT for the `.deb`), so please
check that the problem is still there in the latest version.
